## Agent skills

### Issue tracker

Issues and PRDs for this repo live as local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage state is tracked using standard canonical labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context layout. One central `CONTEXT.md` and `docs/adr/` directory. See `docs/agents/domain.md`.
